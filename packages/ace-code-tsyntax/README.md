# @ace-code/tsyntax

Scoped alias for [**tsyntax**](https://www.npmjs.com/package/tsyntax) — a
lightweight ~13 KB parser for scalar TypeScript-syntax DSL strings, validated
at the type level and at runtime.

This package re-exports `tsyntax` unchanged; it exists only to provide the
scoped name. Prefer the plain [`tsyntax`](https://github.com/AceCodePt/tsyntax)
package unless you need the scope.

```ts
import { dslString, SUPPORTED_KEYWORDS } from "@ace-code/tsyntax";
```
